## TP-002-GetProductCost-Plan
### Назначение:
Объектом тестирования является REST API, реализованный методом GET по следующему шаблону: /products/{productId}/cost?authToken=&count=&start=. Интерфейс позволяет получать стоимость продукта по его уникальному идентификатору, а также дополнительно принимать ряд параметров (authToken, count, start).
### Область тестирования
Функциональные области, которые подлежат тестированию:
- Получение стоимости продукта по идентификатору (productId).
- Обработка корректных и некорректных параметров (count, start).
- Авторизация через параметр authToken.
- Проверка работы API при различных состояниях продукта (готовый/не готовый).
- Контроль HTTP-кодов и содержимого ответов в ситуациях ошибки.
